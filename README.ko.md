# PRIVON

**PRIVON — AI를 쓰기 전, 개인정보 보호를 켜다.**

> PRIVON은 실사용 환경에서의 검증을 위해 배포되는 공개 베타입니다. 1.0 수준의 안정성을
> 보장하지는 않습니다. 이 문서는 릴리스 최종 확인 중인 v0.3.2 후보를 설명합니다.
> v0.3.2가 공개 게시되었다는 뜻은 아닙니다. 검증된 상태는
> [공개 기록](#공개-기록)을 참고하세요.

---

## PRIVON 소개

PRIVON은 Windows용 로컬 우선(local-first) 개인정보 보호 유틸리티입니다.

- 클립보드에 복사한 텍스트에 전화번호·주민등록번호 등 지원되는 개인정보 패턴이 포함되어
  있으면, 지원되는 AI 대상에 직접 붙여넣기 **전에** 클립보드 안에서 로컬로 감지·보호합니다.
  현재 허용된 ChatGPT·Claude 데스크톱 ID와 [지원 범위](#지원-범위)에 적힌 정확한 Chrome
  웹사이트가 여기에 포함됩니다.
- 모든 처리는 사용자의 PC 안에서만 일어납니다. 클립보드 내용이 외부 서버로 전송되지
  않습니다.
- PRIVON은 계속해서 **한국어(KR) 사용 환경**과 **클립보드 경로**를 우선 지원합니다.
  데스크톱과 브라우저 ID를 좁고 엄격하게 인증하므로 이름만 비슷한 실행 파일이나 허용되지 않은
  웹사이트는 인정하지 않습니다. 지원되지 않거나 불확실한 ID는 fail-closed로 동작합니다.

## 30초 시작하기

개발 도구나 명령어 없이, 아래 단계만으로 바로 사용할 수 있습니다.

1. GitHub Release 페이지에서 최신 `PRIVON-*-win-x64.zip` 파일을 내려받습니다.
2. 내려받은 zip 파일을 마우스 오른쪽 버튼으로 클릭 → **압축 풀기(Extract All)** 를 선택합니다.
3. 압축이 풀린 폴더에서 `PRIVON.exe` 를 더블클릭해 실행합니다.
4. 화면 오른쪽 아래 알림 영역(트레이)에 PRIVON 아이콘이 나타나면 정상적으로 실행된
   것입니다.
5. 지원되는 데스크톱 앱을 평소처럼 사용하세요. Chrome 웹 지원을 사용하려면 승인된 PRIVON
   Chrome 확장 프로그램을 설치한 뒤 Settings에서 표시되는 **Connect Chrome**을 직접
   선택해 연결을 완료하세요.

> PRIVON은 현재 활성 창이 허용된 데스크톱 ID이거나, 인증된 Chrome 확장 연결을 사용하는
> 정확한 지원 origin일 때만 동작합니다. 다른 애플리케이션과 웹사이트는 허용되지 않습니다.

## 예시

아래는 실제 개인정보가 아닌 **가상의 예시**입니다.

**복사한 원문**

```
문의 전화 010-1234-5678
```

**PRIVON이 보호한 클립보드 내용**

```
문의 전화 [전화번호1]
```

붙여넣기 전에 클립보드 자체가 바뀌므로, ChatGPT에는 원문 전화번호가 아닌 보호된 형태로
전달됩니다.

## 지원 범위

- Windows 10 / 11 (64비트, win-x64)
- 데스크톱 대상: 현재 허용된 **ChatGPT Windows Desktop Microsoft Store 패키지 ID**와
  인증된 **Claude Desktop** 앱. 이름만 비슷한 실행 파일과 인식되지 않는 ID는 허용하지 않습니다.
- Chrome 웹 대상: 승인된 PRIVON Chrome 확장 프로그램과 인증된 로컬 연결을 통해 접근한
  `https://chatgpt.com`, `https://claude.ai`, `https://gemini.google.com`,
  `https://grok.com`, `https://chat.deepseek.com`만 지원합니다. 다른 origin은 지원하지 않습니다.
- Microsoft Edge 연동은 사용할 수 없으며 이후 버전으로 연기되었습니다.
- Antigravity는 지원하지 않습니다.
- 한국어(KR) 우선 지원
- 클립보드 경로(Clipboard-first) 우선 지원 — 이제 ChatGPT로 전환하기 전에 복사해 둔
  내용도 포함
- 모든 처리는 로컬에서 수행
- 회원가입 불필요

## 지원하는 개인정보 종류

PRIVON이 현재 감지·보호를 시도하는 항목은 다음과 같습니다.

- 전화번호
- 이메일
- 주민등록번호
- 카드번호
- 계좌번호
- 시크릿/토큰처럼 보이는 값 (API 키 등)
- IP 주소
- MAC 주소
- GPS/위치 좌표

> 위 항목이라도 문맥에 따라 놓치거나 다르게 판단될 수 있습니다. PRIVON은 "완벽한 탐지"를
> 목표로 하지 않으며, 아래 [PRIVON이 보장하지 않는 것](#privon이-보장하지-않는-것)을 함께
> 확인해 주세요.

## 확인이 필요한 경우 (NeedsDecision)

민감도가 더 높다고 판단되는 값은 PRIVON이 곧바로 치환하지 않고, 사용자에게 확인 창을 띄워
직접 결정하도록 합니다.

이 확인 창이 제공하는 동작은 **모두 보호(Protect All)** 한 가지뿐입니다. 버튼을
누르면 확인이 필요한 항목이 모두 보호된 뒤 창이 닫힙니다.

## 설정(Settings)

PRIVON 트레이 아이콘을 마우스 오른쪽 버튼으로 클릭 → **Settings** 를 선택하면 설정 창이
열립니다. 현재 실제로 동작하는 기능:

- 전화번호(Phone) 보호 켜기/끄기
- 이메일(Email) 보호 켜기/끄기
- 전화번호 또는 이메일에 대한 정확한 값 예외(exact-value exception) 추가/삭제 (절대
  보호하지 않을 특정 값)
- 보호 범위를 기본값(모든 항목 켜짐)으로 초기화
- 예외 목록 초기화
- 설정한 값은 로컬에 저장되며 재시작 후에도 유지됩니다
- PRIVON의 암호화된 로컬 저장소를 현재 사용할 수 없는 경우, 설정 변경이 저장된 것처럼
  거짓으로 표시하지 않고 이 저하된(degraded) 상태를 정직하게 보여줍니다

아직 동작하지 않는 기능: 이름(Name)·주소(Address)·회사(Company)는 아직 탐지기가 없어서
그 자체의 설정 항목이 없습니다 — 켜고 끌 대상이 없습니다. 설정에는 이미 적용한 변경을
되돌리는 Undo/Restore 기능이 없습니다 — 초기화는 기본값으로 되돌릴 뿐, 이력을 단계별로
되돌리지 않습니다.

### Chrome 연결 및 다시 연결

- **연결되지 않음:** 처음 실행할 때 PRIVON은 읽기 전용 준비 상태 확인을 한 번 수행하고
  **Connect Chrome**을 표시할 수 있습니다. PRIVON 실행이나 Settings 열기만으로 레지스트리나
  manifest를 만들지 않습니다. 연결하려면 사용자가 직접 **Connect Chrome**을 선택해야 합니다.
- **연결됨:** 소유가 확인된 Native Messaging 등록과 manifest가 현재 PRIVON 실행 파일 및
  승인된 확장 프로그램과 일치합니다.
- **연결 업데이트 필요:** 포터블 PRIVON 실행 파일을 옮기면 기존 소유 등록이 이전 경로를
  가리킬 수 있습니다. 알림을 클릭하거나 Settings를 여는 것만으로는 복구되지 않습니다.
  현재 위치를 확인한 뒤 **Reconnect Chrome**을 직접 선택하세요.
- **차단 또는 사용 불가:** PRIVON은 다른 프로그램의 등록을 가져오지 않으며, 출처가 불명확한
  남은 manifest를 조용히 채택하지 않습니다. 확인 실패를 연결 성공으로 표시하지 않습니다.
  충돌 소유자/파일을 먼저 확인하고, 연결을 강제하려고 알 수 없는 등록을 삭제하지 마세요.

Chrome 연결 작업은 Chrome에만 적용됩니다. Edge는 사용할 수 없습니다.

## PRIVON이 보장하지 않는 것

PRIVON은 다음을 보장하거나 주장하지 않습니다.

- 임의의 애플리케이션 또는 웹사이트 보호. [지원 범위](#지원-범위)의 정확한 데스크톱 ID와
  Chrome origin만 허용됩니다.
- Edge 또는 Antigravity 보호. 둘 다 현재 지원 범위 밖입니다.
- 완전한 익명화(anonymization)
- 개인정보보호 규제 준수 인증
- 지원 대상으로 명시된 것 이외의 모든 식별정보에 대한 탐지
- ChatGPT와의 네트워크 통신 가로채기/감시
- 메시지 자동 전송
- 키보드로 직접 입력하는 경로(direct composer typing)에 대한 보호 — PRIVON이 공식적으로
  보장하는 경로는 **클립보드 경로**입니다.
- "붙여넣은 내용이 실제로 보호본과 일치하는지" 확인하는 내부 검증 기능은 존재하지만,
  공개 기능으로 노출되어 있지 않습니다.

## 프라이버시 설계

현재 코드와 테스트로 검증된 사실만 기재합니다.

- 모든 탐지·보호 처리는 로컬에서 수행됩니다.
- 원격 텔레메트리(telemetry)를 전송하지 않습니다.
- 사용 분석(analytics)을 수집하지 않습니다.
- 서드파티 크래시 리포트 SDK를 사용하지 않습니다.
- 진단 로그에 원문 개인정보(raw PII)를 기록하지 않으며, 진단 로그 자체가 **기본값으로
  꺼져** 있습니다. 일반 사용자가 실행하면 아무 로그 파일도 생성되지 않습니다.
- 로컬 상태(신뢰 목록, 예외 목록 등)는 `%LocalAppData%\PRIVON` 아래 암호화되어 저장됩니다.
- 구현된 범위 내에서, Windows 세션 잠금(Win+L) 시 처리 중이던 민감한 메모리 상태(진행 중인
  확인 대기 상태 등)를 즉시 폐기합니다.

## Windows SmartScreen 경고

PRIVON은 아직 코드 서명이 되어 있지 않습니다. 이 때문에 Windows가 "알 수 없는
게시자" 관련 SmartScreen 경고를 표시할 수 있습니다. 이는 정상적인 동작이며, 코드 서명 미적용
소프트웨어에서 흔히 나타나는 안내입니다.

**공식 GitHub Release에서 받은 파일**이라면, 다음과 같이 진행할 수 있습니다.

1. 경고 창에서 **추가 정보(More info)** 를 클릭합니다.
2. **실행(Run anyway)** 을 클릭합니다.

Windows Defender나 SmartScreen 자체를 비활성화할 필요는 없으며, 권장하지도 않습니다.

## 종료 방법

작업 표시줄 알림 영역의 PRIVON 트레이 아이콘을 마우스 오른쪽 버튼으로 클릭한 뒤 **Exit** 를
선택하면 프로그램이 종료됩니다. **Exit는 PRIVON을 종료할 뿐, 삭제나 정리를 수행하지 않습니다.**

### 포터블 복사본 삭제와 남는 상태

압축을 푼 폴더를 삭제하기 전에 트레이 메뉴에서 **자동 시작**을 끄세요. 현재 UI는 Chrome
Native Messaging 등록 전체를 제거하는 일반 삭제 기능을 제공하지 않습니다. PRIVON이 다른
프로그램 소유 또는 충돌 상태로 표시한 레지스트리/manifest를 임의로 삭제하지 마세요.

`PRIVON.exe` 또는 폴더만 삭제하면 Windows 자동 시작 등록, Chrome Native Messaging 등록과
manifest, `%LocalAppData%\PRIVON`의 암호화된 로컬 상태, 진단을 켰을 때 생성된 로그, 설치된
Chrome 확장 프로그램과 브라우저 관리 상태가 남을 수 있습니다. 확장 프로그램은 Chrome에서
제거합니다. 로컬 파일과 남은 소유 등록은 수동 정리가 필요할 수 있습니다. v0.3.2에는 설치
프로그램이나 제거 프로그램이 없습니다.

## 자동 시작 (선택 사항)

PRIVON은 Windows에 로그인할 때 자동으로 실행되도록 선택적으로 설정할 수 있습니다.

- **기본값은 꺼짐(off)** 입니다 — 사용자가 직접 켜지 않는 한 PRIVON은 스스로 Windows
  시작프로그램에 등록되지 않습니다.
- PRIVON 트레이 아이콘 메뉴에서 언제든지 켜고 끌 수 있습니다.
- 켜면 현재 사용 중인 Windows 사용자 계정에 대해서만 등록됩니다 — 관리자 권한이 필요하지
  않으며, 같은 컴퓨터의 다른 사용자 계정에는 영향을 주지 않습니다.
- 자동 시작을 켠 상태에서 압축을 푼 PRIVON 폴더를 나중에 옮기거나 이름을 바꾸면, PRIVON은
  자동 시작이 여전히 정상 동작하는 것처럼 잘못 표시하지 않습니다 — 안전한 방향으로 실패하여
  자동 시작이 꺼진 것으로 표시합니다. 새 위치에서 다시 켜면 다시 등록됩니다.

Native Messaging과 자동 시작은 서로 별도의 절대 실행 파일 경로를 저장합니다. PRIVON을
옮긴 뒤에는 Chrome 연결에 **Reconnect Chrome**을 사용하고, 새 위치에서 자동 시작을 직접
다시 설정하세요. 어느 경로도 조용히 자동 복구되지 않습니다.

PRIVON이 이미 실행 중인 상태에서 다시 실행해도 중복 인스턴스가 생기지 않습니다 — 나중에
실행한 쪽은 곧바로 종료되고, 기존에 실행 중이던 PRIVON(트레이 아이콘, 클립보드 보호)은
그대로 계속 동작합니다.

## 소스에서 직접 빌드하기

> 아래는 일반 사용자를 위한 절차가 아닙니다. 직접 빌드하려는 개발자를 위한 절차입니다.

### 요구 사항

- Windows 10/11
- .NET 10 SDK

### 복원 / 빌드 / 테스트

```powershell
dotnet restore PRIVON.slnx
dotnet build PRIVON.slnx -c Release
dotnet test PRIVON.slnx -c Release
```

### 일반 개발자용 게시(publish)

```powershell
dotnet publish src/Privon.App/Privon.App.csproj `
  -c Release `
  -r win-x64 `
  --self-contained true `
  -p:PublishSingleFile=true `
  -p:PublishReadyToRun=false `
  -p:DebugType=None `
  -o publish/win-x64
```

self-contained win-x64 빌드를 만듭니다 — 최종 사용자가 .NET 런타임을 별도로 설치할 필요가
없습니다. 이는 아래의 인증된(certified) 릴리스 패키징과는 별개인, 일반 로컬 개발자용
publish입니다 — clean-source 검사도, provenance 검증도 수행하지 않으며 ZIP/체크섬도
생성하지 않습니다.

### 인증된(certified) 릴리스 패키징

`tools/publish-release.ps1`은 강화된(hardened) 인증 릴리스 패키징 경로입니다: working
tree가 clean한지 검사하고, 정확한 Git commit에 고정된 격리된 detached worktree에서만
빌드하며, 빌드된 실행 파일이 요청한 버전과 해당 commit의 SHA를 실제로 모두 담고 있는지
검증하고, 금지된 산출물(테스트 바이너리, PDB, 로컬 사용자 데이터 파일)을 스캔한 뒤에야
ZIP + SHA-256 체크섬을 생성합니다. `-Version`은 필수이며 기본값이 없습니다.

```powershell
.\tools\publish-release.ps1 -Version 0.3.2
```

(위 명령은 호출 형태를 보여줍니다. 이 README는 인증된 v0.3.2 데스크톱 릴리스 패키지가
이미 공개되었다고 주장하지 않습니다.)

## 검증 현황

- PRIVON의 release gate는 릴리스 후보를 패키징하기 전에 전체 로컬 자동화 테스트
  스위트(Core/Detection/Windows/Storage/App)가 100% 통과(GREEN)하고 빌드 경고 0개·오류
  0개일 것을 요구합니다. 이는 개발 중에 실행하는 로컬 자동화 테스트이며, 이 저장소는
  현재 GitHub Actions를 비롯한
  어떤 CI도 실행하지 않습니다. (정확하고 날짜가 명시된 통과 개수는 이 상시 문서가 아니라
  릴리스 증거/릴리스 노트에 남깁니다.)
- 실제 Windows 클립보드를 대상으로 한 320회 실측 시도: 낮음/중간 위험도 개인정보는 보호가
  필요한 모든 경우에 자동으로 보호·검증되었고, 높은 위험도(NeedsDecision) 값은 자동으로
  조용히 보호되지 않고 사용자 확인을 위해 그대로 남겨짐이 정상적으로 확인됨
- 실제 Windows + 실제 ChatGPT Windows Desktop 환경에서의 클립보드 보호 동작 확인(smoke
  test) 통과 — 다른 애플리케이션에서 먼저 복사한 뒤 ChatGPT로 전환하는 경우 포함
- 과거 데스크톱 smoke test에서 지원되지 않는 애플리케이션에 개입하지 않음을 확인했습니다.
  Chrome 웹 지원은 별도의 확장 프로그램 및 권한 부여 테스트로 검증합니다.
- Windows 세션 잠금(Win+L) 관련 동작 확인(smoke test) 통과
- 선택적 자동 시작 기능을 실제 Windows 재부팅/로그인으로 켠 상태·끈 상태 양쪽 모두 확인
  통과
- PRIVON이 이미 실행 중일 때 다시 실행해도 중복 인스턴스가 생기지 않음을 확인 통과
- Release용 publish 산출물 실행 확인(smoke test) 통과

이 검증은 테스트된 범위와 조건 안에서의 결과이며, "모든 환경에서 완벽하게 동작함"을
의미하지 않습니다.
